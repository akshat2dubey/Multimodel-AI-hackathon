# Jalnetra — runtime dependencies
# Verified on Python 3.14.2 (Windows, this project's development machine): the full
# test suite passes and every wheel resolves from PyPI. Python 3.10-3.12 should work
# (nothing here is 3.13+ only) but was NOT tested for this submission — treat the
# 3.14 statement as the verified one.
#
#   python -m pip install -r requirements.txt
#
# Heavy but optional ML/GIS extras are grouped at the bottom.

# --- Core geospatial -------------------------------------------------------
rasterio>=1.3          # GeoTIFF I/O, rasterization, mask vectorisation
geopandas>=0.14        # OSM GeoJSON handling (pulls in pandas + pyproj + pyogrio)
shapely>=2.0           # Geometry operations
scipy>=1.10            # distance transforms, Gaussian smoothing (DEM, demo data),
                          # 3x3 median speckle filter for Sentinel-1 tifs

# --- Core numerics ---------------------------------------------------------
numpy>=1.24

# --- Road-network analysis -------------------------------------------------
networkx>=3.0          # cut-off settlement reachability (BFS over road graph)

# --- Deep learning (flood segmentation) ------------------------------------
# scripts/inference.py imports torch unconditionally (the flood mask comes from
# either the U-Net or the log-ratio baseline computed with torch tensors), so
# this is a required dependency, not an extra. It is by far the heaviest one:
# ~250 MB of CPU wheels. If a machine cannot take it, the honest alternative is
# not to run inference there — there is no torch-free mask path today.
torch>=2.0             # CPU wheels are the default on Windows
torchvision>=0.15      # ResNet-34 encoder for ResNetUNet

# --- Dashboard -------------------------------------------------------------
# Flask only: the dashboard and its API share one origin, so no CORS package is
# installed (or imported). flask-cors was a declared dependency that nothing
# used; it was removed in T36.
flask>=3.0

# --- Progress + CLI --------------------------------------------------------
tqdm>=4.65

# --- Copernicus Data Space client (needed only for real downloads) ---------
# NOTE: this is 'cdse-client' (import name: cdse). The package literally named
# 'cdse' does NOT exist on PyPI, so `pip install cdse` / a `cdse>=2.0` pin will
# fail with "No matching distribution found".
#
# Authenticate with OAuth2 client credentials (no interactive login):
#   1. Register free at https://dataspace.copernicus.eu/
#   2. Create an OAuth client under Identity & Access Management
#   3. set CDSE_CLIENT_ID=... and set CDSE_CLIENT_SECRET=...
# Required by download_sentinel.py and download_sentinel2.py. Without valid
# credentials those scripts exit non-zero — they no longer write placeholders.
# download_dem.py needs no account (AWS Open Data bucket) and no credentials.
cdse-client>=1.2

pytest>=8.0           # tests/ — logic tests on generated toy data (no network,
                        # no credentials, no GPU; `python -m pytest -q`)
